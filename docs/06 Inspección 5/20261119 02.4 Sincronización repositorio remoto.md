## 3. Cómo publicar este cierre

```text
git status
git add "docs/06 Inspección 5" "docs/07 Consolidado 2" src README.md
git commit -m "docs: cierra la Inspección 5 y el software con archivo de ayuda"
git push origin develop
git checkout main
git merge develop
git push origin main
git checkout develop
```

Después del push, GitHub debe mostrar el mismo identificador que `git log -1 --oneline` en `main` y en `develop`.
