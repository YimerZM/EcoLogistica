## 1. Qué recorren

`tests/test_e2e.py` levanta la misma API que usa la página, en un puerto libre. No abre el navegador y no usa el puerto 8765. El recorrido de pantalla está en la demostración del Sprint 3.

## 2. Cómo ejecutarlas

Desde `src/backend`:

```text
python -m unittest tests.test_e2e -v
```

Junto con las de sistema:

```text
python -m unittest tests.test_reglas tests.test_e2e -v
```

El resultado esperado de las dos juntas es `Ran 11 tests` y `OK`.

## 3. Pasos de E2E-01

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Clave incorrecta del operador | La API responde que las credenciales no son válidas |
| 2 | `operador@ecologistica.test` / `operador123` | Devuelve token |
| 3 | Registrar ABC-123 con 800 kg | Estado DISPONIBLE |
| 4 | Punto en Lima | Rechazo |
| 5 | Punto en Huancayo, -12.07, -75.21 | Se guarda con método WGS84 |
| 6 | Pedido explosivo | Rechazo y no entra en la lista |
| 7 | Pedido general de 10 kg | Estado PENDIENTE |
| 8 | Listar pedidos | Hay un pedido |
| 9 | El operador intenta crear un usuario | 403 |
| 10 | El administrador crea `cliente@ecologistica.test` como Contratante | 201 |
| 11 | Generar ruta | 201, una parada en Huancayo |

El paso 10 crea ese correo durante la prueba. Por eso el sistema no lo trae sembrado al arrancar.
