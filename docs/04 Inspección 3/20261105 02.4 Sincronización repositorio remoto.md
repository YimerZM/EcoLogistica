## 2. Cómo quedar al día

```text
git checkout main
git pull origin main
```

## 3. Cómo publicar un cierre

```text
git status
git add docs src
git commit -m "docs: describe el cambio"
git push origin main
```

Después del push, la comprobación es abrir https://github.com/YimerZM/EcoLogistica y ver el mismo commit que muestra `git log -1 --oneline`.
