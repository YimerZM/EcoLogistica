# Pruebas de sistema

**Proyecto:** EcoLogística  
**Equipo:** Híbridos  
**Fecha:** 2026-11-05  
**Alcance:** reglas del núcleo operativo entregado en los Sprint 1 y 2

[Volver al README principal](../../README.md)

## 1. Cómo ejecutarlas

Desde `src/backend`:

```text
python -m unittest tests.test_reglas -v
```

No requieren el navegador. Comprueban el comportamiento del sistema en las reglas y en los casos de uso.

## 2. Casos

| ID | Condición | Resultado esperado | Código |
|---|---|---|---|
| SIS-01 | El bloqueo de 15 minutos ya venció y el usuario inicia sesión | El contador vuelve a cero antes de validar la clave | `test_el_contador_se_restablece_al_iniciar_si_el_bloqueo_vencio` |
| SIS-02 | El bloqueo sigue vigente | El contador no se limpia y el acceso queda bloqueado | `test_el_bloqueo_vigente_no_se_limpia_al_iniciar` |
| SIS-03 | Tercer intento fallido | El usuario queda bloqueado 15 minutos | `test_al_tercer_fallo_bloquea_quince_minutos` |
| SIS-04 | Tipo de carga distinto de general | El pedido se rechaza | `test_rechaza_carga_prohibida_y_acepta_general` |
| SIS-05 | Distrito Lima | La geolocalización se rechaza | `test_la_geolocalizacion_exige_los_tres_distritos` |
| SIS-06 | Clave inválida y luego clave válida | La primera no abre sesión. La segunda sí | `test_login_valido_despues_de_un_fallo_no_deja_el_contador_como_condicion_de_acceso` |
| SIS-07 | Pedido explosivo y luego pedido general | El primero no se guarda. El segundo queda PENDIENTE | `test_pedido_prohibido_no_se_guarda` |

## 3. Fuera de este conjunto

La generación de rutas, el mapa y PostgreSQL no tienen prueba de sistema porque todavía no están en el incremento.
