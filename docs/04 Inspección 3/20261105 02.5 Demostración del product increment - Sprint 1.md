# Demostración del product increment — Sprint 1

**Proyecto:** EcoLogística  
**Equipo:** Híbridos  
**Fecha de esta guía:** 2026-11-05  
**Incremento:** historias del Sprint 1 que el Sprint 2 dejó ejecutables

[Volver al README principal](../../README.md)

El Sprint 1 cerró la especificación de US-001, US-003, US-004 y US-005. El programa que se demuestra es ese mismo alcance. El mapa y el cálculo de rutas no forman parte de este incremento.

## 1. Encender la aplicación

Desde `src/backend`:

```text
python -m ecologistica
```

Abrir http://127.0.0.1:8765.

## 2. Recorrido

| Paso | Qué hacer en la página | Qué decir | Resultado |
|---|---|---|---|
| 1 | Pulsar Iniciar sesión con la clave cambiada a una incorrecta | El contador se evalúa al comenzar | No abre la sesión |
| 2 | Volver a entrar con `operador@ecologistica.test` y `operador123` | La clave válida abre el núcleo | Aparece el operador y Cerrar sesión |
| 3 | Registrar placa `ABC-123` y capacidad `800` | Esto es US-003 | El mensaje dice que el vehículo quedó registrado |
| 4 | Registrar un punto en Huancayo, latitud `-12.07`, longitud `-75.21` | La geolocalización admitida es WGS84 | El punto aparece con el método WGS84 |
| 5 | Elegir ese punto, peso `10` y tipo Explosivo | RN-016 impide carga prohibida | El pedido no se guarda |
| 6 | Repetir el pedido con tipo General | US-005 | El pedido queda PENDIENTE |

## 3. Cierre de la demostración

El incremento del Sprint 1, ya ejecutable, cubre sesión, vehículo, punto y pedido. La ruta sobre el mapa queda para el siguiente incremento.
