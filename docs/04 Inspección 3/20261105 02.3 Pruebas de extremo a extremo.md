# Pruebas de extremo a extremo (E2E)

**Proyecto:** EcoLogística  
**Equipo:** Híbridos  
**Fecha:** 2026-11-05

[Volver al README principal](../../README.md)

## 1. Qué recorren

La prueba levanta la misma API que usa la página y recorre el incremento de punta a punta: sesión, vehículo, punto y pedido. No abre el navegador. El recorrido de pantalla está en la demostración del incremento.

## 2. Cómo ejecutarlas

Desde `src/backend`:

```text
python -m unittest tests.test_e2e -v
```

## 3. Recorrido automatizado

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Entrar con una clave incorrecta | La API responde que las credenciales no son válidas |
| 2 | Entrar con `operador@ecologistica.test` y `operador123` | La API devuelve un token |
| 3 | Registrar un vehículo | La API lo devuelve con estado DISPONIBLE |
| 4 | Registrar un punto en Lima | La API lo rechaza |
| 5 | Registrar un punto en Huancayo, -12.07, -75.21 | La API lo guarda con método WGS84 |
| 6 | Registrar un pedido explosivo | La API lo rechaza y no lo lista |
| 7 | Registrar un pedido general | La API lo guarda en estado PENDIENTE |

El código está en `src/backend/tests/test_e2e.py`.
