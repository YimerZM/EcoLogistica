Cada requisito se redacta como escenario de calidad. El escenario nombra, en este orden, la **fuente**, el **estímulo**, el **entorno**, el **artefacto**, la **respuesta** y la **medida**.

| ID | Categoría ISO 25010 | Escenario de calidad (fuente, estímulo, entorno, artefacto, respuesta, medida) |
|---|---|---|
| RNF-001 | Eficiencia de desempeño | **Fuente:** usuario autenticado. **Estímulo:** consulta de pedidos o vehículos. **Entorno:** operación normal del MVP. **Artefacto:** API. **Respuesta:** devolver el resultado de la consulta. **Medida:** latencia P95 ≤ 1.5 s. |
| RNF-002 | Seguridad | **Fuente:** persona sin sesión válida. **Estímulo:** llamada a un recurso protegido. **Entorno:** sistema en operación. **Artefacto:** módulo de autenticación. **Respuesta:** rechazar la llamada y registrar el intento. **Medida:** 100 % de los recursos protegidos exige sesión y rol antes de ejecutar la operación. |
| RNF-003 | Fiabilidad | **Fuente:** usuario del sistema. **Estímulo:** acceso en el horario de operación acordado. **Entorno:** ambiente de demostración del MVP. **Artefacto:** aplicación web. **Respuesta:** atender la solicitud. **Medida:** disponibilidad ≥ 99.0 % en el mes de operación medido. |
| RNF-004 | Fiabilidad | **Fuente:** usuario autorizado. **Estímulo:** alta o cambio de un pedido, vehículo o punto. **Entorno:** operación normal. **Artefacto:** base de datos. **Respuesta:** guardar el dato solo si cumple las claves y las reglas. **Medida:** 100 % de las operaciones confirmadas conserva la integridad referencial. |
| RNF-005 | Usabilidad | **Fuente:** planificador o contratante. **Estímulo:** completar su tarea principal. **Entorno:** navegador de escritorio. **Artefacto:** interfaz web. **Respuesta:** terminar la tarea con los mensajes de error visibles. **Medida:** ≥ 80 % de las personas de la prueba de aceptación termina la tarea sin ayuda. |
| RNF-006 | Compatibilidad | **Fuente:** usuario. **Estímulo:** abrir la aplicación. **Entorno:** Chrome, Edge o Firefox en la versión vigente de soporte. **Artefacto:** interfaz web. **Respuesta:** mostrar y ejecutar las funciones del incremento. **Medida:** 100 % de las funciones del incremento opera en esos tres navegadores. |
| RNF-007 | Mantenibilidad | **Fuente:** equipo de desarrollo. **Estímulo:** cambio de una regla de negocio. **Entorno:** repositorio del proyecto. **Artefacto:** código del módulo afectado. **Respuesta:** incorporar el cambio sin romper los otros módulos. **Medida:** ≥ 80 % de las pruebas unitarias existentes sigue en verde. |
| RNF-008 | Eficiencia de desempeño | **Fuente:** hasta 50 usuarios concurrentes. **Estímulo:** consultas simultáneas del MVP. **Entorno:** prueba de carga controlada. **Artefacto:** API. **Respuesta:** atender las consultas dentro del umbral. **Medida:** 50 usuarios concurrentes con P95 ≤ 1.5 s. Este umbral no describe un sistema de alta concurrencia. |
| RNF-009 | Fiabilidad | **Fuente:** infraestructura. **Estímulo:** interrupción del servicio. **Entorno:** ambiente de demostración. **Artefacto:** aplicación y base de datos. **Respuesta:** reponer el servicio y conservar lo ya confirmado. **Medida:** RTO ≤ 30 min y RPO ≤ 15 min. |
| RNF-010 | Seguridad | **Fuente:** usuario autenticado. **Estímulo:** alta, cambio o rechazo de una operación. **Entorno:** sistema en operación. **Artefacto:** registro de auditoría. **Respuesta:** guardar actor, acción y momento. **Medida:** 100 % de las operaciones marcadas como auditables deja registro. |
| RNF-011 | Seguridad | **Fuente:** operador logístico. **Estímulo:** registro de un pedido con producto peligroso o prohibido. **Entorno:** operación en El Tambo, Huancayo y Chilca. **Artefacto:** servicio de pedidos. **Respuesta:** rechazar el pedido y no guardarlo. **Medida:** 100 % de las cargas distintas de GENERAL queda fuera del sistema. |
