Un interesado es quien afecta el proyecto, resulta afectado o usa el sistema. El usuario de prueba no es interesado: no representa una organización ni una decisión. Quien tiene interés participa en el sistema según ese nivel, y el equipo de desarrollo lo acompaña. No sustituye a ningún rol.
