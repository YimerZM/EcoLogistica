## 2. Propósito y justificación

Las entregas en El Tambo, Huancayo y Chilca se planifican con recorridos que no integran capacidad del vehículo, ventana horaria y emisiones. Eso alarga la distancia, el tiempo, el combustible y el CO₂ estimado. EcoLogística autoriza la construcción de un sistema web que genere rutas con esos criterios y que permita replanificar cuando cambien pedidos o vehículos. El proyecto existe para ese problema, dentro de los tres distritos, y esta acta confiere al director la autoridad para coordinarlo.

## 4. Requisitos de alto nivel

1. Autenticar usuarios y aplicar el bloqueo por intentos al iniciar la sesión.
2. Registrar vehículos, puntos de entrega y pedidos.
3. Geolocalizar cada punto mediante coordenadas WGS84 obtenidas por georreferenciación de la dirección.
4. Generar y reoptimizar rutas respetando capacidad y ventana de tiempo.
5. Rechazar el transporte de productos peligrosos o prohibidos.
6. Estimar distancia, tiempo, combustible y CO₂, y mostrarlos junto con el mapa.
7. Operar únicamente en El Tambo, Huancayo y Chilca.

Quedan fuera: GPS físico en vehículos, flota real, otras ciudades e integración con ERP no definidos.

## 5. Riesgos macro

| ID | Riesgo | Impacto probable |
|---|---|---|
| R-01 | El algoritmo no respeta capacidad o ventana en los casos de prueba. | Alto: retrabajo del módulo de rutas. |
| R-02 | No se consiguen coordenadas WGS84 válidas para los puntos. | Medio: las rutas no se pueden calcular. |
| R-03 | El calendario académico comprime las pruebas del MVP. | Alto: cierre con historias pendientes. |
| R-04 | Se intenta transportar carga prohibida sin una regla explícita. | Alto: riesgo operativo y de seguridad pública. |
