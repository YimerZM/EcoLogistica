EcoLogística

Planificación de carga general en El Tambo, Huancayo y Chilca. La coordenada es WGS84. El mapa es un esquema del valle, no el GPS del vehículo.

Volver al ingreso

Cómo entrar

Desde la carpeta src/backend ejecute python -m ecologistica y abra http://127.0.0.1:8765. Deje esa terminal abierta.

El contratante no viene creado. Lo registra el administrador. Tres claves incorrectas bloquean el acceso 15 minutos. Si ese plazo ya pasó, el contador vuelve a cero al empezar el siguiente ingreso.

Recorrido de demostración

  1. Entre como operador.
  2. En Panel, pulse Preparar datos de El Tambo, Huancayo y Chilca.
  3. En Rutas, pulse Generar ruta. ECO-101 lleva 52 kg de 800. La pantalla muestra 11.73 km. Esa cifra no incluye el regreso a la base.
  4. En Indicadores, periodo Todo el registro, pulse Calcular. El CO₂ usa 0.21 kg por kilómetro: 2.46 kg.
  5. Para reoptimizar, primero cambie un pedido pendiente, un punto o registre otro pedido. Sin ese cambio, el sistema se niega.

Si algo no responde

  • Si el navegador dice que 127.0.0.1 rechazó la conexión, el proceso no está encendido. Vuelva a ejecutar python -m ecologistica.
  • Al cerrar el servidor se pierden los datos de la sesión. Vuelva a cargar el ejemplo.
  • Un pedido explosivo que no aparece en la lista fue rechazado. Use carga general.
  • Las pruebas no necesitan la página: desde src/backend, python -m unittest tests.test_reglas tests.test_e2e -v.
